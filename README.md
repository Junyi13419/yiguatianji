# 一卦天机（yiguatianji）

赛博命理网站 —— AI 驱动的在线八字排盘与命运推演平台。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架（导航、弹窗、脚本引用） |
| `css/style.css` | 赛博朋克霓虹样式 |
| `js/app.js` | 应用逻辑：视图渲染、登录、付费闭环 |
| `js/engine.js` | 排盘引擎：四柱、十神、五行、大运流年 |
| `js/cyber-bg.js` | 矩阵数字雨背景动效 |
